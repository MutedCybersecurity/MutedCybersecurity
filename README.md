  # Muted Cybersecurity

  **Security research · Penetration testing · Coordinated vulnerability disclosure**

  [Website](https://mut3dcybersecurity.com/) · [Research](https://github.com/MutedCybersecurity/security-research) · [Templates](https://github.com/MutedCybersecurity/disclosure-templates) · [Español](README.es.md) · [Contact](mailto:cybersec@mut3dcybersecurity.com)
</div>

We investigate security boundaries, validate findings in controlled environments, and work with maintainers on remediation and responsible publication. Our public work links to upstream advisories and provides practical reporting resources.

## How we work

<img src="assets/research-workflow.svg" alt="Research workflow: define the boundary, validate in isolation, report privately, coordinate publication" width="100%">

We keep verified observations separate from hypotheses, use synthetic data where possible, and treat the upstream maintainer's advisory as the authoritative record. See our [research approach](https://github.com/MutedCybersecurity/security-research/blob/main/docs/research-approach.md).

## Contact and collaboration

<img src="assets/contact-band.svg" alt="Contact Muted Cybersecurity for private security coordination" width="100%">

For coordinated security work or questions about our public research, email **[cybersec@mut3dcybersecurity.com](mailto:cybersec@mut3dcybersecurity.com)**. For a vulnerability in another project, use that project's preferred private security channel. Please do not post unpublished details in public issues or pull requests.

For corrections to this profile, see our [contribution guide](CONTRIBUTING.md). For sensitive matters, use the [private contact guidance](SECURITY.md).
