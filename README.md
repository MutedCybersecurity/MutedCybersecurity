  # Muted Cybersecurity

  **Security research · Penetration testing · Coordinated vulnerability disclosure**

  [Website](https://mut3dcybersecurity.com/) · [Contact](mailto:cybersec@mut3dcybersecurity.com)
</div>

We investigate security boundaries, validate findings in controlled environments, and work with maintainers on remediation and responsible publication. Our public repositories contain published research records and practical documentation. Unpublished reports stay in private coordination channels.

## Work with us

For coordinated security work or questions about our public research, email **[cybersec@mut3dcybersecurity.com](mailto:cybersec@mut3dcybersecurity.com)**. For a vulnerability in another project, use that project's preferred private security channel. Please do not post unpublished details in public issues or pull requests.
