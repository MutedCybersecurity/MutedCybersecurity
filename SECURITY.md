# Security contact

For a security issue in this profile repository, or a question involving unpublished research by Muted Cybersecurity, contact [cybersec@mut3dcybersecurity.com](mailto:cybersec@mut3dcybersecurity.com) privately.

For a vulnerability in another project, use that project's preferred private security reporting channel. Do not include undisclosed findings, credentials, personal data, or private advisory material in a public pull request.

This repository documents public work and brand resources. Published advisory pages remain the authoritative source for technical scope, fixes, and credit.
