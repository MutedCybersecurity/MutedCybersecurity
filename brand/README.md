# Muted Cybersecurity · Brand resources

This page keeps our public name, visual assets, and attribution format consistent across GitHub, advisories, and presentations.

## Name and contact

| Use | Exact text |
| --- | --- |
| Public name | **Muted Cybersecurity** |
| GitHub account | **[@MutedCybersecurity](https://github.com/MutedCybersecurity)** |
| Research contact | **[cybersec@mut3dcybersecurity.com](mailto:cybersec@mut3dcybersecurity.com)** |
| Website | **[mut3dcybersecurity.com](https://mut3dcybersecurity.com/)** |

For a GitHub security advisory, credit the account `@MutedCybersecurity` under the contribution type that fits the actual work. If the advisory includes a separate written acknowledgement, use **Muted Cybersecurity**. GitHub's upstream advisory remains the source of truth for the final credit.

Ready-to-use wording is available in [attribution examples](attribution.md).

## Visual system

| Element | Value | Intended use |
| --- | --- | --- |
| Deep navy | `#071B3B` | Main background |
| Cyan | `#00E5E5` | Monogram, rules, and highlights |
| Ice white | `#F4FBFF` | Main text on navy |
| Soft blue | `#A6E7EC` | Secondary text on navy |

Typography uses common sans-serif fonts, with clear headings and short paragraphs. Graphics use simple geometric shapes so they remain legible at small sizes.
