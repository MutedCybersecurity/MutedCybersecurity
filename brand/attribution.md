# Public attribution examples

Use these short examples when a maintainer asks how to record our credit. The actual GitHub credit type should match the contribution in that advisory.

## GitHub advisory credit

- **Account:** [`@MutedCybersecurity`](https://github.com/MutedCybersecurity)
- **Public name:** Muted Cybersecurity
- **Contact:** [cybersec@mut3dcybersecurity.com](mailto:cybersec@mut3dcybersecurity.com)

## Written acknowledgement

English:

> We thank Muted Cybersecurity for responsibly reporting this issue and assisting with coordinated disclosure.

Español:

> Agradecemos a Muted Cybersecurity la comunicación responsable de este problema y su colaboración en la divulgación coordinada.

Use the wording only when it accurately describes the contribution and the maintainer agrees. For an advisory with several reporters, list everyone according to the project's attribution policy.
